iCloud Mail

Apple doesn't offer sign-in for third-party mail apps, so you'll need an app-specific password — a limited password just for this app, separate from your real Apple ID password.

How to get an app-specific password
  1. Go to appleid.apple.com and sign in
  2. Go to Sign-In and Security
  3. Select App-Specific Passwords → Generate
  4. Copy the password it gives you — you'll paste it below, not your real password

Yahoo Mail

Same idea as iCloud — Yahoo also requires an app-specific password rather than your normal login.

How to get an app-specific password
  1. Go to your Yahoo Account Security settings
  2. Find Generate app password
  3. Name it "Unsubscribely" and generate
  4. Copy the password it gives you — you'll paste it below, not your real password
